## About

Catppina is a collection of Catppuccin ports rebuilt with my own color palette.

The generated themes are available in [`dist`](dist/).

## 🛠️ Building

The themes are generated from the ports in [`ports`](ports/) using [`just`](https://github.com/casey/just).

Build every port:

```sh
just build
```

Build a specific port:

```sh
just build_helix
```

List all available recipes:

```sh
just --list
```
